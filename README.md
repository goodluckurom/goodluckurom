# Goodluck Urom

Full-stack developer in Lagos. I build web applications and the services behind them, mostly in TypeScript, and in Go when the backend should stay small.

Client and company work stays in private repositories. These are the projects I can show.

## Projects

**[LinkMeet](https://github.com/goodluckurom/linkmeet)** — video meetings in the browser. Media goes peer to peer over WebRTC. Signaling runs on Bun and Hono. The app also records meetings and shows live captions. [Open the app](https://linkmeet.vercel.app)

**[Gopher-Drop](https://github.com/goodluckurom/Gopher-Drop)** — send files between a computer and a phone on the same network. A Go server only introduces the two devices. The file itself moves over a WebRTC data channel.

**[Messenger](https://github.com/goodluckurom/messenger-app)** — a chat application on Next.js, with accounts, Prisma, and Pusher for live messages. [Open the app](https://messenger-app-brown.vercel.app)

## Stack

TypeScript, React, Next.js, Node.js, Go, PostgreSQL, Prisma, React Native.
